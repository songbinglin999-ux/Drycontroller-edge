# DryController - 烘干控制系统

## 项目简介
DryController是一个专业的烘干控制系统，用于精确控制烘干过程中的温度、湿度和风速等参数，确保烘干效果达到最佳状态。

## 功能特性
- 实时监测和控制温度
- 湿度检测与调节
- 风速控制
- 烘干时间设置
- 自动/手动模式切换
- 数据记录与统计

## 技术架构
- 前端：Web界面，用于数据展示和控制操作
- 后端：控制算法和数据处理
- 通信：支持多种协议与传感器/执行器通信
