0. 报警分级与通用规则

报警等级定义

等级标记含义响应要求
INFOI提示性信息，不影响生产记录日志，操作员知晓
预警W参数偏离正常范围，尚未影响生产操作员关注，准备干预
报警A参数超限，需立即处理声光报警 + 上报 cloud-ops + 操作员介入
联锁E危险状态，自动触发保护动作自动停机/安全化 + 声光报警 + 上报 + 人工确认

通用规则

报警延迟所有报警需持续 T_debounce（默认 3s）才确认，避免瞬态抖动误报
报警锁存报警触发后锁存，即使参数恢复正常，也需人工确认复位（防止一闪而过被漏看）
报警抑制设备停机期间，该设备相关的过程报警自动抑制（如 M3 停机时 FTT1 高温不报警）；安全类报警不抑制
坏值处理传感器坏值（断线/超量程/冻结）不产生过程报警，而是触发「传感器故障」报警（见安全契约 §2.10）
报警记录所有报警事件记录到 edge-daq 审计日志，含时间戳、信号名、当前值、限值

7. 报警响应流程

报警触发（信号超限持续 T_debounce）
  │
  ├─ INFO → 记录日志 → 操作员知晓
  │
  ├─ 预警(W) → 记录日志 → 操作员关注/准备干预
  │
  ├─ 报警(A) → 声光报警 + 记录日志 + 上报 cloud-ops
  │              → 操作员介入处理 → 确认复位
  │
  └─ 联锁(E) → 自动保护动作（停机/安全化）
                 → 声光报警 + 上报 + 锁存
                 → 操作员排查原因 → 处理 → 手动复位 → 恢复生产

复位规则：
  - 预警/报警：参数恢复正常后自动消除，但事件记录保留
  - 联锁：参数恢复后仍锁存，必须人工确认复位
  - 安全类联锁（急停/跑偏等）：必须排除故障后手动复位
