工艺控制逻辑（上位机 / Edge）
版本：v0.3-draft  ·  日期：2026-06-15  ·  状态：框架搭建中
v0.3 改归属（2026-06-15）：本文从「PLC 交付物」改为上位机（edge）工艺控制设计——工艺控制落地、控制状态机、软点策略与软件侧安全兜底由 edge 负责。PLC 提供软点控制层、参数同步、报警同步、状态同步、执行、采集、ACK/NAK、无扰切换、HMI/edge 控制权锁和心跳丢失切本地。
关联文档：I/O 点表 · 超限报警规范 · 安全契约（PLC 交付）
说明：本文定义每台设备的控制方法与编排逻辑。橙色斜体为待工艺确认的占位值。

本文归属：上位机（edge）工艺设计，非集成商 / PLC 交付物。 分层原则：工艺控制智能（状态机、配方、模式、给料/风机目标、过程判断）和软件侧安全兜底在上位机；PLC 只实现接口、同步、执行与本地控制权兜底（软点层、参数/报警/状态同步、限幅、斜坡、ACK/NAK、无扰切换、HMI/edge 控制权锁、心跳丢失切本地、实际频率跟随）。本文中的工艺逻辑由我方（edge）实现，不要求 PLC 推理“为什么要调”。本文涉及顺序联锁处会标明哪部分是 PLC 执行/仲裁接口，哪部分是 edge 正常编排。

0. 总则

控制层级

层级说明示例
安全联锁硬接线或安全 PLC，不经过上位机，最高优先级急停、拉绳跑偏、热继跳闸
设备保护联锁PLC 程序内实现，过流/过载/坏值等电流超限→停机、反转清堵
工艺联锁上下游设备启停顺序、料位联动逆启顺停、缺料停下游
工艺算法edge 用多变量因果判断计算变频目标和软点电流高 + 温度/出料温度/湿度判断是过料、供热不足还是排湿不足
执行控制PLC 接收 edge 目标频率，做限幅、斜坡、ACK/NAK、实际频率跟随edge 给 VFM2/VF2 目标频率，PLC 按安全规则执行

低层级可覆盖高层级：安全联锁 > 设备保护联锁 > 工艺联锁 > PLC 执行限幅/斜坡 > edge 工艺算法目标。温度只作为采样输入；本系统不写温度目标，不做 PLC 温度 PID。

PV / SP / MV 约定

术语在本系统中的含义例子
PV过程量 / 反馈量，主要由 PLC 采集后给 edge 使用I_M5、FTT2、T_OUT2、MT1、VFM2 实际反馈
SPedge 算法或 operator-touch 给 PLC 的目标值VFM2_FREQ_SP、VF2_FREQ_SP、整线模式软点
MVPLC / 变频器实际输出给执行机构的量PLC 限幅和斜坡后的 VFM2/VF2 实际频率

若 PLC 把“实际频率反馈”当 PV 去追“目标频率 SP”，这只是执行器跟随环，不是工艺闭环。工艺 PV 仍然是电流、温度、出料温度、湿度、料位、下游负载等过程量；因果消歧和目标生成必须留在 edge。

通用电机清堵逻辑（适用于所有带 CT 的定频电机）

正常运行中检测到 I_x > I_overflow（过流阈值）
  │
  ├─ 第 1 次：停机 → 等待 T_reverse 秒 → 反转 T_clear 秒 → 停 → 正转
  │
  ├─ 第 2 次：同上
  │
  └─ 第 3 次仍过流：停机 → 置「清堵报警」DO → 等待人工介入
      （连续 N_fail 次反转清堵失败后不再自动重试）

参数（占位）：
  T_reverse = 2s（反转前等待）
  T_clear   = 3s（反转持续时间）
  N_fail    = 3（最大重试次数）
  I_overflow = 按各电机额定电流的 150%（待确认）

通用启停条件符号说明

符号含义
START_COND启动条件（全部满足才允许启动）
STOP_COND停止条件（任一满足即停止）
INTERLOCK联锁条件（触发后强制停机并锁定，需复位）
RUN_FB运行反馈（DI，确认电机实际在转）

1. 上料电机 料斗补料

1.1 M1 — 料斗1→料斗2 LL1 控制

控制对象M1 电机（DO 启/停），料斗1→料斗2 输送
检测信号LL1（料斗2料位 DI）、I-M1（电流 AI）
控制目的维持料斗2料位在设定范围内，保证下游不断料

控制逻辑

┌─────────────────────────────────────────────────────┐
│                   M1 上料控制                         │
├─────────────────────────────────────────────────────┤
│                                                     │
│  IDLE（待机）                                         │
│    │  LL1 = 0（料斗2无料）                            │
│    ▼                                                │
│  启动 M1                                            │
│    │                                                │
│    ├─ LL1 = 1（料斗2有料）→ 停 M1 → 进入 PAUSE       │
│    │                                                │
│    └─ 超时 T_feed_max 秒仍 LL1 = 0                   │
│        → 停 M1 → 报警「料斗1缺料」（上游无料）         │
│                                                     │
│  PAUSE（暂停）                                        │
│    │  等待 T_pause 秒                                │
│    ▼                                                │
│  再次检查 LL1                                        │
│    ├─ LL1 = 1 → 保持停机，继续 PAUSE 循环             │
│    └─ LL1 = 0 → 回到 IDLE，重新启动 M1               │
│                                                     │
│  任何时刻：I-M1 过流 → 执行通用清堵逻辑（§0）          │
└─────────────────────────────────────────────────────┘
参数符号占位值说明
补料超时T_feed_max120s启动后此时间内 LL1 未触发→缺料报警
暂停间隔T_pause30s料满后暂停时间，避免频繁启停
过流阈值I_M1_overflow额定×150%见 §0 通用清堵逻辑
缺料报警—DO 声光 + 上报见 报警规范

1.2 M2 — 料斗2→料斗3 LL2 控制

控制对象M2 电机（DO 启/停），料斗2→料斗3 输送
检测信号LL2（料斗3料位 DI）、I-M2（电流 AI）
控制目的维持料斗3料位，为 VFM1 供料

控制逻辑

与 M1 逻辑相同（LL2 触发 → 停 M2 → PAUSE 循环），
区别：缺料报警对象为「料斗2缺料」。

异常处理：
  I-M2 过流 → 通用清堵逻辑（§0）
  T_feed_max 内 LL2 未触发 → 报警「料斗2缺料」
参数符号占位值说明
补料超时T_feed_max120s同 M1
暂停间隔T_pause30s同 M1
过流阈值I_M2_overflow额定×150%

2. 变频给料 主机进料调节

2.1 VFM1 — 料斗3→主机1 edge 算法目标

控制对象VFM1 变频给料机目标频率（PLC 软点 SP）
主要 PVI-M3、FTT1、VFM1/VF1 实际反馈、M3/M4 状态、LL3
控制目的edge 根据主机1负载和风温能力生成 VFM1 目标频率；PLC 只做限幅、斜坡、联锁和频率跟随

edge 算法逻辑

edge 每个控制周期计算 VFM1_FREQ_SP：

  1. 先判定是否允许给料
     M3 未运行 / M4 未运行 / LL3 满 / PLC 返回 NAK → VFM1_FREQ_SP = 0 或保持安全低值

  2. 再做负载-干燥能力消歧
     I-M3 高 + FTT1 正常/偏高       → 更像过料或机械负载偏高 → 下调 VFM1 目标
     I-M3 高 + FTT1 偏低或 VF1 反馈低 → 更像供热/风量不足     → 小幅下调或保持 VFM1，并提示检查供热/风路
     I-M3 低 + FTT1 稳定            → 可按斜坡小幅上调 VFM1 目标

  3. 输出目标频率
     VFM1_FREQ_SP = clamp_and_ramp(freq_base + load_trim + thermal_trim)
     edge 输出的是目标；PLC 执行限幅、斜坡、联锁、ACK/NAK。

PLC 执行/本地切换：
  I-M3 到过载级 → PLC 可停 VFM1 或停 M3（按安全契约）
  通信异常 / 坏值 / 手动模式 → PLC 拒绝 edge 目标并返回原因码
参数符号占位值说明
电流低限I_low额定×60%低于此值可增加进料
电流高限I_high额定×100%高于此值减少进料（= 报警预警点，见报警规范 §2.1）
过载停料I_overload额定×120%停 VFM1 + 报警
频率下限freq_min10 Hz变频器最低运行频率
频率上限freq_max50 Hz变频器额定频率
基础频率freq_base30 Hz稳态运行频率
单周期最大调整freq_step_maxTBD Hzedge 算法限速；PLC 仍需二次斜坡

2.2 VFM2 — 料斗4→主机2 edge 算法目标

逻辑同 VFM1，但主机2要把出料口温度纳入消歧，不能只看 I-M5，也不应直接用 MT1 做快调。

  • 主令电流改为 I-M5（主机2电流）
  • 热 / 排湿输入：FTT2、TT1、T_OUT2、VF2 实际反馈
  • 下游联锁 / 负载输入：M5、M6、M7、M8 及对应电流趋势
  • T_OUT2 高通常说明主机2出料端蒸汽/热湿状态偏重，优先结合 VF2 与 FTT2 判断是排湿不足还是供热不足
  • 如果上调 VF2 后 FTT2 明显下降，且 TT1 不足，edge 应停止继续加风，转为“供热不足/负荷过高”诊断，并下调或保持 VFM2 目标
  • MT1 距离主机2过程太远，不参与主机2快速目标计算；只可作为长期趋势和整线质量背景

2.3 VFM3 — 料斗5→主机4 edge 算法目标

逻辑同 VFM1，但主机4靠近最终湿度点，可以把 MT1 放进慢修正。

  • 主令电流改为 I-M10（主机4电流）
  • 热 / 排湿输入：FTT3、TT2、T_OUT4、VF3 实际反馈
  • 质量输入：MT1 作为最终湿度慢修正，不能作为秒级快调
  • 增加 LL4 缓冲料位逻辑：LL4 = 0（料斗5缺料）→ 降频或停 VFM3 → 请求上游 M9 补料
  • 下游联锁 / 负载输入：M10、M11、M12、M13、M14 及对应电流趋势
  • T_OUT4 高 + MT1 高 + VF3 反馈低：优先判断末段排湿能力不足；若加风导致 FTT3 下跌且 TT2 低，则转为供热不足 / 负荷过高诊断

3. 主机系统 干燥核心

3.1 主机1（M3 + VF1 + FTT1）

组成M3（主电机 DO）、VF1（变频风机 AO）、FTT1（风温 AI）
控制目的edge 计算主机1风机目标频率；PLC 执行目标频率和安全联锁，不做温度 PID

M3 主电机

启动条件（全部满足）：
  - 上游 VFM1 就绪
  - 下游 M4 就绪
  - 无安全联锁触发
  - 无过载报警

停止条件（任一满足）：
  - I-M3 > 额定×120% → 停 VFM1（先停进料降负荷，停料级）
  - I-M3 > 额定×150% → 停 M3（联锁停机级）
  - 安全联锁触发
  - 人工停机 / Edge 软急停

联锁：
  M3 故障 → 停 VFM1（上游断料）+ 停 M4（下游停止出料）

VF1 风机 + FTT1 观测

控制策略：edge 风机目标频率算法

  PV：FTT1、VF1 实际反馈、I-M3、VFM1 实际反馈、M3/M4 状态
  SP：VF1_FREQ_SP（edge 输出给 PLC 的目标频率）
  MV：PLC 限幅/斜坡后的 VF1 实际频率

  FTT1 只用于判断风温/供热/风量状态，不作为 PLC 温度 PID 的 PV。

  edge 判断：
    FTT1 偏低 + I-M3 高 → 供热/风量不足或负荷偏大，优先提示检查风路/供热并限制进料
    FTT1 稳定 + I-M3 偏高 → 过料或机械负载偏高，优先下调 VFM1
    FTT1 偏高但负载正常 → 可小幅提高 VF1 或保持，由工艺阈值决定

PLC 执行/本地切换：
  M3 未运行 → VF1 降速到安全低值或停机
  FTT1 坏值（断线/超量程/冻结）→ PLC 拒绝依赖该值的自动目标，切手动/安全模式（见安全契约 §2.10）
参数符号占位值说明
风温观察带FTT_observe_bandTBD ℃edge 算法用，不是 PLC 温控目标
风机频率范围freq_min–max10–50 HzPLC 安全限幅仍为最终约束
风机单周期调整vf_step_maxTBD Hzedge 限速，避免风温/蒸汽状态被快速扰动
低温运营报警T_low_alarmTBD ℃提醒人工检查供热，不自动停料

3.2 主机2（M5 + VF2 + FTT2）

逻辑同主机1，区别：

  • 热源来自锅炉1（TT1），TT1 只作为供热能力输入；无温度闭环目标
  • 新增 T_OUT2：主机2出料口温度，用于判断蒸汽量/排湿状态
  • 主机电流用 I-M5
  • 下游联锁 M6/M7/M8（主机2→发酵仓）

3.3 发酵仓（M8）无独立风机/热源

组成M8（主电机 DO）、I-M8（电流 AI）
特殊发酵仓 无独立风机和温度检测，靠主机2余热 + 物料自身热量继续干燥
 
启动条件：
  - M6 运行（上游主机2在出料）
  - M9 就绪（下游可出料）
  - 无过载

停止条件：
  - I-M8 过载
  - 上游 M6 停机 → 延时 T_delay 后停 M8（排空残料）
  - 下游 M9 故障

联锁：
  M8 故障 → 停 M6（上游断料）+ 停 M9（下游停出料）

3.4 主机4（M10 + VF3 + FTT3）

逻辑同主机1，区别：

  • 热源来自锅炉2（TT2），TT2 只作为供热能力输入；无温度闭环目标
  • 新增 T_OUT4：主机4出料口温度，用于判断末段蒸汽量/排湿状态
  • 主机电流用 I-M10
  • 进料用 VFM3，下游联锁 M11/M12/M13/M14
  • MT1 距离主机4最近，可参与整线慢修正；仍不能作为秒级快调

4. 输送联锁 物料流转

4.1 M4 — 主机1→料斗4

启动条件：
  - M3 运行（上游主机1在工作）
  - LL3 = 0（料斗4未满）

停止条件：
  - LL3 = 1（料斗4满）→ 停 M4
  - M3 停机 → 延时 T_empty 后停 M4（排空管道残料）
  - I-M4 过流 → 清堵逻辑

联锁：
  M4 故障 → 停 M3 + 停 VFM1（上游全部停止，防止堵料堆积）

4.2 M6/M7/M8 — 主机2→发酵仓 的输送链

联锁关系（故障级联保护）：

  M5（主机2）
    ↓ 物料流向
  M6（主机2→发酵仓 输送）
    ↓
  M7（发酵仓 进料传送带，串联 M6）
    ↓
  M8（发酵仓）

  故障处理：
    M6 故障 → 停 M5（上游主机2停止出料）+ 停 M7
    M7 故障 → 停 M6 + 停 M5（上游停止进料）
    M8 故障 → 停 M7 + 停 M6 + 停 M5（上游全部停止）

  启停顺序：
    启动：M8 先启 → M7 → M6 → M5（逆序启动，下游先就绪）
    停止：M5 先停 → 延时 → M6 → 延时 → M7 → 延时 → M8（顺序停机，排空残料）

4.3 M9 — 发酵仓→料斗5

启动条件：M8 运行 + LL4 = 0（料斗5未满）
停止条件：LL4 = 1 → 停 M9 / M8 停机 → 延时停 M9
联锁：M9 故障 → 停 M8 → 停 M6 → 停 M5（整条主机2-3链停止）

4.4 M11 — 主机4→料斗6

启动条件：M10 运行
停止条件：M10 停机 → 延时 T_empty 停 M11 / I-M11 过流清堵
联锁：M11 故障 → 停 M10 + 停 VFM3

4.5 M12 — 料斗6→滚筛

启动条件：M13（滚筛）运行
停止条件：M13 停机 → 延时停 M12
联锁：M12 故障 → 停 M11（上游断料）

注：料斗6 有 MT1 湿度检测，作为主机4/整线慢修正输入（§8），不直接驱动主机2快调。

5. 滚筛与出料 末端设备

5.1 M13 — 滚筛

启动条件：
  - 下游料斗7 或出料通道就绪
  - 无安全联锁

停止条件：
  - I-M13 堵筛（过流）→ 清堵逻辑

MT1 反馈 → 慢修正主机4和整线稳态基准：

  MT1 > H_target + H_band  → 湿度偏高

9. 整线启停顺序

逆序启动（下游先就绪）

启动顺序（箭头方向 = 启动先后）：

  M14(出料) → M13(滚筛) → M12 → M11 → M10(主机4)
                              ↑
                           M9 → M8(发酵仓) → M7 → M6 → M5(主机2)
                                                 ↑
                                              M4 → M3(主机1)

  锅炉：M15/M16 独立启动（先于主机，确保供热就绪）
  变频给料：VFM1/VFM2/VFM3 最后启动（主机就绪后再进料）

  每步启动后等待 RUN_FB 确认，确认后再启上游。

顺序停机（上游先停，排空残料）

停止顺序：

  VFM1/VFM2/VFM3（停进料）→ 等待 → M3/M5/M8/M10（停主机）
    → 延时 → M4/M6/M7/M9/M11（排空输送）→ M12 → M13 → M14

  锅炉：主机全部停后再停 M15/M16（余热利用）

  每步延时 T_empty（TBD 秒）排空残料后，再停下游。
