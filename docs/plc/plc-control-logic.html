PLC 控制逻辑
版本：v0.1-draft  ·  日期：2026-06-04  ·  状态：框架搭建中
关联文档：I/O 点表 · 超限报警规范 · 安全契约
说明：本文档定义每台设备的控制方法与联锁逻辑。橙色斜体为待工艺确认的占位值。

0. 总则

控制层级

层级说明示例
安全联锁硬接线或安全 PLC，不经过上位机，最高优先级急停、拉绳跑偏、热继跳闸
设备保护联锁PLC 程序内实现，过流/过载/坏值等电流超限→停机、反转清堵
工艺联锁上下游设备启停顺序、料位联动逆启顺停、缺料停下游
过程控制PID / 调节回路，维持工艺参数风温→风机调速、湿度→进料量
Edge 指令远程设定值下发，受安全契约约束edge 写温度目标 / 链速

低层级可覆盖高层级：安全联锁 > 设备保护 > 工艺联锁 > 过程控制 > Edge 指令。

通用电机清堵逻辑（适用于所有带 CT 的定频电机）

正常运行中检测到 I_x > I_overflow（过流阈值）
  │
  ├─ 第 1 次：停机 → 等待 T_reverse 秒 → 反转 T_clear 秒 → 停 → 正转
  │
  ├─ 第 2 次：同上
  │
  └─ 第 3 次仍过流：停机 → 置「清堵报警」DO → 等待人工介入
      （连续 N_fail 次反转清堵失败后不再自动重试）

参数（占位）：
  T_reverse = 2s（反转前等待）
  T_clear   = 3s（反转持续时间）
  N_fail    = 3（最大重试次数）
  I_overflow = 按各电机额定电流的 150%（待确认）

通用启停条件符号说明

符号含义
START_COND启动条件（全部满足才允许启动）
STOP_COND停止条件（任一满足即停止）
INTERLOCK联锁条件（触发后强制停机并锁定，需复位）
RUN_FB运行反馈（DI，确认电机实际在转）

1. 上料电机 料斗补料

1.1 M1 — 料斗1→料斗2 LL1 控制

控制对象M1 电机（DO 启/停），料斗1→料斗2 输送
检测信号LL1（料斗2料位 DI）、I-M1（电流 AI）
控制目的维持料斗2料位在设定范围内，保证下游不断料

控制逻辑

┌─────────────────────────────────────────────────────┐
│                   M1 上料控制                         │
├─────────────────────────────────────────────────────┤
│                                                     │
│  IDLE（待机）                                         │
│    │  LL1 = 0（料斗2无料）                            │
│    ▼                                                │
│  启动 M1                                            │
│    │                                                │
│    ├─ LL1 = 1（料斗2有料）→ 停 M1 → 进入 PAUSE       │
│    │                                                │
│    └─ 超时 T_feed_max 秒仍 LL1 = 0                   │
│        → 停 M1 → 报警「料斗1缺料」（上游无料）         │
│                                                     │
│  PAUSE（暂停）                                        │
│    │  等待 T_pause 秒                                │
│    ▼                                                │
│  再次检查 LL1                                        │
│    ├─ LL1 = 1 → 保持停机，继续 PAUSE 循环             │
│    └─ LL1 = 0 → 回到 IDLE，重新启动 M1               │
│                                                     │
│  任何时刻：I-M1 过流 → 执行通用清堵逻辑（§0）          │
└─────────────────────────────────────────────────────┘
参数符号占位值说明
补料超时T_feed_max120s启动后此时间内 LL1 未触发→缺料报警
暂停间隔T_pause30s料满后暂停时间，避免频繁启停
过流阈值I_M1_overflow额定×150%见 §0 通用清堵逻辑
缺料报警—DO 声光 + 上报见 报警规范

1.2 M2 — 料斗2→料斗3 LL2 控制

控制对象M2 电机（DO 启/停），料斗2→料斗3 输送
检测信号LL2（料斗3料位 DI）、I-M2（电流 AI）
控制目的维持料斗3料位，为 VFM1 供料

控制逻辑

与 M1 逻辑相同（LL2 触发 → 停 M2 → PAUSE 循环），
区别：缺料报警对象为「料斗2缺料」。

异常处理：
  I-M2 过流 → 通用清堵逻辑（§0）
  T_feed_max 内 LL2 未触发 → 报警「料斗2缺料」
参数符号占位值说明
补料超时T_feed_max120s同 M1
暂停间隔T_pause30s同 M1
过流阈值I_M2_overflow额定×150%

2. 变频给料 主机进料调节

2.1 VFM1 — 料斗3→主机1 主令：I-M3 / MT1

控制对象VFM1 变频给料机（AO 频率指令 + DO 启停）
检测信号I-M3（主机电流 AI）、MT1（末端湿度 AI）、LL3（料斗4料位 DI）
控制目的根据主机电流和末端湿度调节进料量，平衡干燥效率与电机负载

控制逻辑

正常运行：
  进料频率 = f(I-M3, MT1)

  调节策略：
    1. 主令回路 — 电流调节
       I-M3 < I_low   → 可增加进料（主机负载低，有余力）
       I-M3 > I_high（额定×100%）    → 减少进料（同时触发预警）
       I-M3 > I_overload（额定×120%） → 停 VFM1（停料降负荷）
       I-M3 > 额定×150%              → 停 M3（联锁停机，见 §3.1）

    2. 辅助回路 — 湿度修正
       MT1 > H_high   → 降低进料（干燥不足，减少湿料输入）
       MT1 < H_low    → 可增加进料（干燥充分）

    3. 综合输出
       freq_out = freq_base × K_current × K_humidity
       限幅在 [freq_min, freq_max]

联锁：
  LL3 = 1（料斗4满）→ 停 VFM1（下游溢料保护）
  M3 未运行 → 停 VFM1（主机停则停进料）
  M4 未运行 → 停 VFM1（出料堵则停进料）
参数符号占位值说明
电流低限I_low额定×60%低于此值可增加进料
电流高限I_high额定×100%高于此值减少进料（= 报警预警点，见报警规范 §2.1）
过载停料I_overload额定×120%停 VFM1 + 报警
湿度高限H_highTBD %高于此值降频
湿度低限H_lowTBD %低于此值可增频
频率下限freq_min10 Hz变频器最低运行频率
频率上限freq_max50 Hz变频器额定频率
基础频率freq_base30 Hz稳态运行频率

2.2 VFM2 — 料斗4→主机2 主令：I-M5

逻辑同 VFM1，区别：

  • 主令电流改为 I-M5（主机2电流）
  • 下游联锁改为 M5 + M6 状态
  • LL3 料位作为 VFM1 的下游溢料保护，VFM2 用 料斗4+主机2 相关信号（待确认）

2.3 VFM3 — 料斗5→主机4 主令：I-M9 / LL4

逻辑同 VFM1，区别：

  • 主令电流改为 I-M9（主机4电流）
  • 增加 LL4 缓冲料位逻辑：LL4 = 0（料斗5缺料）→ 降频或停 VFM3 → 请求上游 M8 补料
  • 下游联锁改为 M9 + M10 状态

3. 主机系统 干燥核心

3.1 主机1（M3 + VF1 + FTT1）

组成M3（主电机 DO）、VF1（变频风机 AO）、FTT1（风温 AI）
控制目的维持主机1干燥温度在工艺设定范围

M3 主电机

启动条件（全部满足）：
  - 上游 VFM1 就绪
  - 下游 M4 就绪
  - 无安全联锁触发
  - 无过载报警

停止条件（任一满足）：
  - I-M3 > 额定×120% → 停 VFM1（先停进料降负荷，停料级）
  - I-M3 > 额定×150% → 停 M3（联锁停机级）
  - 安全联锁触发
  - 人工停机 / Edge 软急停

联锁：
  M3 故障 → 停 VFM1（上游断料）+ 停 M4（下游停止出料）

VF1 风机 + FTT1 温度闭环

控制策略：PID 温度控制

  目标：FTT1 维持在 T_target（工艺设定值）
  输出：VF1 频率

  FTT1 > T_target + T_band  → 增大风速（降温）
  FTT1 < T_target - T_band  → 减小风速（保温）
  FTT1 > T_alarm_high       → 高温报警 + 增料 / 强制降温
  FTT1 < T_alarm_low        → 低温报警（供热异常）

  VF1 输出限幅：[freq_min, freq_max]

联锁：
  M3 未运行 → VF1 降速到最低或停机（主机停则风机降速保安全）
  FTT1 坏值（断线/超量程/冻结）→ 切手动 / 安全模式（见安全契约 §2.10）
参数符号占位值说明
温度目标T_targetTBD ℃由工艺部门确定，edge 可远程写入
调节死区T_band±5 ℃在此范围内不调节
高温报警T_alarm_highTBD ℃见报警规范
低温报警T_alarm_lowTBD ℃见报警规范
PID 参数Kp / Ki / KdTBD现场整定
风机频率范围freq_min–max10–50 Hz

3.2 主机2（M5 + VF2 + FTT2）

逻辑同主机1，区别：

  • 热源来自锅炉1（TT1），温度闭环目标由锅炉供热能力决定
  • 主机电流用 I-M5
  • 下游联锁 M6（主机2→主机3 输送）

3.3 主机3（M7）无独立风机/热源

组成M7（主电机 DO）、I-M7（电流 AI）
特殊主机3 无独立风机和温度检测，靠主机2余热 + 物料自身热量继续干燥
 
启动条件：
  - M6 运行（上游主机2在出料）
  - M8 就绪（下游可出料）
  - 无过载

停止条件：
  - I-M7 过载
  - 上游 M6 停机 → 延时 T_delay 后停 M7（排空残料）
  - 下游 M8 故障

联锁：
  M7 故障 → 停 M6（上游断料）+ 停 M8（下游停出料）

3.4 主机4（M9 + VF3 + FTT3）

逻辑同主机1，区别：

  • 热源来自锅炉2（TT2）
  • 主机电流用 I-M9
  • 进料用 VFM3，下游联锁 M10

4. 输送联锁 物料流转

4.1 M4 — 主机1→料斗4

启动条件：
  - M3 运行（上游主机1在工作）
  - LL3 = 0（料斗4未满）

停止条件：
  - LL3 = 1（料斗4满）→ 停 M4
  - M3 停机 → 延时 T_empty 后停 M4（排空管道残料）
  - I-M4 过流 → 清堵逻辑

联锁：
  M4 故障 → 停 M3 + 停 VFM1（上游全部停止，防止堵料堆积）

4.2 M6/M7 — 主机2→主机3 的输送链

联锁关系（故障级联保护）：

  M5（主机2）
    ↓ 物料流向
  M6（主机2→主机3 输送）
    ↓
  M7（主机3）

  故障处理：
    M6 故障 → 停 M5（上游主机2停止出料）+ 停 M7（下游主机3停止）
    M7 故障 → 停 M6 + 停 M5（上游全部停止）

  启停顺序：
    启动：M7 先启 → M6 → M5（逆序启动，下游先就绪）
    停止：M5 先停 → 延时 → M6 → 延时 → M7（顺序停机，排空残料）

4.3 M8 — 主机3→料斗5

启动条件：M7 运行 + LL4 = 0（料斗5未满）
停止条件：LL4 = 1 → 停 M8 / M7 停机 → 延时停 M8
联锁：M8 故障 → 停 M7 → 停 M6 → 停 M5（整条主机2-3链停止）

4.4 M10 — 主机4→料斗6

启动条件：M9 运行
停止条件：M9 停机 → 延时 T_empty 停 M10 / I-M10 过流清堵
联锁：M10 故障 → 停 M9 + 停 VFM3

4.5 M11 — 料斗6→滚筛

启动条件：M12（滚筛）运行
停止条件：M12 停机 → 延时停 M11
联锁：M11 故障 → 停 M10（上游断料）

注：料斗6 有 MT1 湿度检测，湿度数据反馈到 VFM1–VFM3 调节（§8）

5. 滚筛与出料 末端设备

5.1 M12 — 滚筛

启动条件：
  - 下游料斗7 或出料通道就绪
  - 无安全联锁

停止条件：
  - I-M12 堵筛（过流）→ 清堵逻辑
  - 上游 M11 停机 → 延时 T_empty 停 M12（筛完残料）

注：若 M12 为变频，转速可调；当前按定频 DO 设计

5.2 M13 — 料斗7→出料

启动条件：
  - 料斗7有料（待加料位检测或靠 M12 运行推断）
  - 无安全联锁

停止条件：
  - I-M13 过流清堵
  - 人工停机

注：M13 为最终出料，无下游联锁；需确保出料通道畅通

6. 锅炉 供热系统

6.1 锅炉1 B1（M14 + TT1）

控制对象M14（锅炉1上料电机 DO）、TT1（锅炉温度 AI）
检测信号LL5（燃料料位 DI）、TT1（温度 AI）、I-M14（电流 AI）
供热对象主机2（干燥热风）

M14 上料控制

逻辑同 M1（LL5 控制补料）：
  LL5 = 0（缺燃料）→ 启动 M14
  LL5 = 1（有燃料）→ 停 M14 → PAUSE 循环
  T_feed_max 内 LL5 未触发 → 报警「锅炉1缺燃料」

  I-M14 过流 → 清堵逻辑

TT1 温度监测

TT1 持续监测锅炉1温度：

  TT1 < T_boiler_low   → 低温报警（炉子可能熄火/故障）
  TT1 > T_boiler_high  → 超温报警（危险）
  TT1 在正常范围 → 正常

  注：当前阶段锅炉燃烧控制由锅炉自身完成（独立控制器），
      PLC 只做温度监测和报警，不直接控制燃烧。
      若后续需要 PLC 闭环控制，需增加 AO 控制燃料阀/给料频率。

联锁：
  TT1 > T_boiler_emergency → 强制停 M14（停止供料）+ 报警
  LL5 超时无反馈 → 报警「锅炉1缺燃料」
参数符号占位值说明
低温报警T_boiler_lowTBD ℃低于此值说明炉子故障
超温报警T_boiler_highTBD ℃高于此值危险
紧急超温T_boiler_emergencyTBD ℃停上料 + 报警
缺燃料超时T_feed_max120s同 M1

6.2 锅炉2 B2（M15 + TT2）

逻辑同锅炉1，区别：

  • 上料电机 M15、料位 LL6、温度 TT2
  • 供热对象：主机4
  • TT2 超温报警（与 TT1 独立阈值）

8. 末端湿度闭环

检测点MT1（料斗6，末端湿度 AI）
控制目标成品湿度在工艺合格范围内
调节手段VFM1 / VFM2 / VFM3 进料量 + VF1 / VF2 / VF3 风速
 
MT1 反馈 → 修正各主机进料基准值：

  MT1 > H_target + H_band  → 湿度偏高
    → 降低 VFM1/VFM2/VFM3 频率（减少进料量）
    → 可选：增大 VF1/VF2/VF3 风速（加强干燥）

  MT1 < H_target - H_band  → 湿度偏低（过度干燥）
    → 可增加进料量（提高产能）

  MT1 > H_alarm             → 湿度超限报警

注：MT1 是整线末端的综合反馈，调节时应渐进，避免大幅波动。
    建议用低增益慢积分的 PI 控制，响应周期 TBD 分钟。
参数符号占位值说明
湿度目标H_targetTBD %由工艺确定
调节带H_band±TBD %死区

9. 整线启停顺序

逆序启动（下游先就绪）

启动顺序（箭头方向 = 启动先后）：

  M13(出料) → M12(滚筛) → M11 → M10 → M9(主机4)
                              ↑
                           M8 → M7(主机3) → M6 → M5(主机2)
                                                 ↑
                                              M4 → M3(主机1)

  锅炉：M14/M15 独立启动（先于主机，确保供热就绪）
  变频给料：VFM1/VFM2/VFM3 最后启动（主机就绪后再进料）

  每步启动后等待 RUN_FB 确认，确认后再启上游。

顺序停机（上游先停，排空残料）

停止顺序：

  VFM1/VFM2/VFM3（停进料）→ 等待 → M3/M5/M7/M9（停主机）
    → 延时 → M4/M6/M8/M10（排空输送）→ M11 → M12 → M13

  锅炉：主机全部停后再停 M14/M15（余热利用）

  每步延时 T_empty（TBD 秒）排空残料后，再停下游。
